# Institution logos

Drop official logo PNGs here to replace the generated colour badges.
File name = the institution `key` in `lib/core/institution/institution.dart`:

kbank, scb, bbl, ktb, bay, ttb, gsb, baac, ghb, kkp, cimb, uob, tisco, lhb,
thai_credit, promptpay, paotang, truemoney, shopeepay

Square images (e.g. 128×128) work best; they are clipped to a circle.
Use logos only in line with each brand's usage guidelines.
